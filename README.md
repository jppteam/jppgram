# j++gram documentation

this is the official documentation repository for **j++gram** — a messenger built by the j++ community.

the docs cover platform behavior, internal policies, and technical specifications relevant to users, developers, and contributors.

## navigating the docs

full documentation is maintained in the [wiki](https://github.com/jppteam/jppgram/wiki) section of this repository. below is an overview of what's currently available.

more pages will be added over time as the platform evolves.

## contributing

spotted something outdated or missing? feel free to open an issue or submit a pull request. for larger changes, it's best to open an issue first to discuss what you'd like to change.

when contributing, please keep the same style as the existing docs — lowercase, concise, and clear.
